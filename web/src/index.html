RouteWhat it does
GET /print/{path}A template filled with its sample data
POST /print/{path}A template filled with the JSON data of the body
GET /documents/{path}A document of the server, as it is
POST /renderAny document, with its styles, data and options
GET /files/templates, GET /files/documentsThe templates and the documents, for the editor
GET /files/templates/{path}, GET /files/documents/{path}The files of a template or a document, for the editor
GET /schemaThe schema dev.stxt.pdf of the engine
GET /fonts, GET /fonts/{id}The fonts of the server, for the previews of the editor
GET /healthThe versions, without token Open

/print, /documents and /render take ?format=pdf|svg|stxt and &debug=true.
